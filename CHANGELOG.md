# Changelog

Все значимые изменения проекта ZMP.

## [1.1.0] — 2026-08-07

### Добавлено
- **Каталог модов на базе GitHub-репозиториев** — вместо мёртвого Zapret Marketplace теперь каталог строится из релизов любого GitHub-репозитория (по умолчанию `peachoff/Zapret-Mods`): каждый релиз репозитория — это мод.
- **Несколько сохранённых репозиториев** (`~/.zmp_repos.json`) с быстрым переключением между ними в шапке окна.
- **Установка модов из локального ZIP-архива** — новая вкладка «Из ZIP» вместо устаревшей «По slug».
- **Поддержка `ZMP_GITHUB_TOKEN`** — для обхода rate-лимитов GitHub API.
- **Новая иконка приложения** — переработанный дизайн, добавлен векторный `icon.svg`, перегенерирован `icon.ico`.

### Исправлено
- **AppImage не запускался** — в сборку не попадал Pillow (`ModuleNotFoundError: No module named 'PIL'`). Зависимость добавлена в `pyproject.toml`, AppImage снова работает.
- **Версия из `pyproject.toml`** — версия для артефактов и тега релиза теперь берётся из `pyproject.toml`, а не задаётся вручную (локальная сборка и CI).

### Удалено
- Мёртвый клиент Zapret Marketplace API (`api_client.py`, `marketplace.py`).
- Модуль эмуляции устройства (`device.py`).
- Локальный сервер (`server.py`).
